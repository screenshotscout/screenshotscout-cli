# Security Policy

## Supported versions

Security fixes are provided for the latest published version of Screenshot Scout CLI.

## Reporting a vulnerability

Email suspected vulnerabilities privately to [support@screenshotscout.com](mailto:support@screenshotscout.com). Do not open a public issue for an undisclosed vulnerability.

Never include live Screenshot Scout access keys, secret keys, authorization headers, signatures, generated capture URLs, captured content, or other customer data in a report. Revoke any credential that may have been exposed and use clearly marked synthetic values in reproduction steps.

Include the affected CLI version, operating system, Node.js version, observed impact, and minimal reproduction details that do not contain secrets.
