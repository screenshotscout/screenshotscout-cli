# Security Policy

## Supported versions

Screenshot Scout CLI has not published a supported release yet.

## Reporting a vulnerability

Email suspected vulnerabilities privately to [support@screenshotscout.com](mailto:support@screenshotscout.com). Do not open a public issue for an undisclosed vulnerability.

Never include live Screenshot Scout access keys, secret keys, authorization headers, signatures, screenshot URLs, captured content, or other customer data in a report. Revoke any credential that may have been exposed and use clearly marked synthetic values in reproduction steps.

Include the affected version or commit, the observed impact, and minimal reproduction details that do not contain secrets.
